# Обработчики событий в JavaScript

## 1. События мыши

- `click` — клик (нажатие + отпускание).
- `dblclick` — двойной клик.
- `mouseenter` / `mouseleave` — курсор вошёл/вышел из элемента (не всплывают!).
- `mouseover` / `mouseout` — аналоги, но всплывают.
- `mousedown` / `mouseup` — нажатие/отпускание кнопки мыши.
- `mousemove` — движение мыши внутри элемента.
- `contextmenu` — клик правой кнопкой.

## 2. События клавиатуры

- `keydown` — клавиша нажата (вызывается при удержании).
- `keyup` — клавиша отпущена.
- `keypress` — устаревшее (не используй).

## 3. События форм

- `submit` — отправка формы.
- `focus` / blur — элемент получил/потерял фокус.
- `input` — изменение значения (`<input>`, `<textarea>`).
- `change` — значение изменилось и зафиксировано (например, после потери фокуса).

## 4. События касаний (для мобильных устройств)

- `touchstart` — палец коснулся экрана.
- `touchmove` — палец движется по экрану.
- `touchend` — палец убран.

## 5. События видимости

- `DOMContentLoaded` — `HTML` загружен (без стилей и изображений).
- `load` — страница и все ресурсы загружены.
- `beforeunload` / `unload` — закрытие страницы.

## 6. События для доступности (`ARIA`)

- `focusin` / `focusout` — аналоги `focus`/`blur`, но всплывают.
